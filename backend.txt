 package.json file contains the list of dependencies and scripts in a project

 package.lock.json specifies their respective versions

 Dependencies are packages required for your application to run in production (runtime), such as Express or Axios.

 DevDependencies are packages needed only during the development, testing, or build process, such as Jest, ESLint, or Webpac

 npm - node package manager

 fs - filesystem 

 version - major/minor/patch  (3.4.2)

 the ^ in version installs the latest version

 http - u send a req , the server processes it , then it sends a response . the way machine communicates

ping is used to get ip address 

ports are endpoints to specify particular processes running on a system

create - post
read - get
update - put
delete - delete

http - 80 & https - 443 //default values

2xx - success
200 - successful
204 - success but no content is shown

3xx - redirection
301 - moved to a new url
304 - resource not modified

4xx - client error
400 - bad request ( server could not understand the request due to invalid syntax(like typo))
401 - unauthorized (request requires user authentication)
403 - forbidden refuses to authorise the request
404 - not found

5xx - server error 
500 - internal server error 
502 - bad gateway 

Body(or payload) - contains the actual data which goes to the server

Middleware refers to functions that sit between the incoming HTTP request (req) and the final response (res) for Authentication & Authorization , Data Parsing: Converts raw incoming request data into usable JavaScript objects etc , ends req res cycle
